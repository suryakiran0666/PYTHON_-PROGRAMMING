1. Problem Statement
Convert travel expenses into a base currency using exchange rates and conversion fees. Compare total spending with the budget and identify the largest expense category.
2. Algorithm
1. Input budget, exchange rate, and expenses.
2. Convert expenses and add conversion fees.
3. Calculate total spending.
4. Find the largest expense category.
5. Compare spending with the budget and display results.
6. 5. Sample Input
Budget: 10000
Exchange rate: 80
Fee percentage: 2
Food expense: 20
Travel expense: 50
Hotel expense: 40
6. Sample Output
Total: 8976.0
Largest: Travel
Within Budget
