1. Problem Statement
Calculate event expenses, participant contributions, sponsorship shortfall, and the minimum registrations required to break even.
2. Algorithm
1. Input event costs, sponsorship, and registration fee.
2. Calculate total expenses and sponsorship shortfall.
3. Calculate participant contribution and break-even registrations.
4. Display the financial details.
3. Flowchart:(Mermaid):
flowchart TD
    A([Start]) --> B[/Input costs, sponsorship, fee/]
    B --> C[Calculate total expenses]
    C --> D[Calculate sponsorship shortfall]
    D --> E[Calculate break-even registrations]
    E --> F[/Display financial report/]
    F --> G([End])
5. Sample Input
Venue: 5000
Equipment: 2000
Catering: 10000
Transport: 3000
Certificates: 1000
Sponsorship: 8000
Registration fee: 200
6. Sample Output
Total Cost: 21000.0
Sponsorship Shortfall: 13000.0
Break-even Registrations: 65
